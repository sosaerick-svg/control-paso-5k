# Control de Paso 5K

Registro de paso por puntos de control, llegada a meta y resultados de la Carrera 5K de la Jornada Ignaciana 2026 (URL, Campus San Luis Gonzaga S.J. de Zacapa).

- Página: `index.html` (sitio estático en GitHub Pages).
- Datos: Supabase, proyecto `control-paso-5k`. Todo el acceso pasa por funciones RPC que validan el código del juez o el PIN de coordinación.
- No guardar en este repositorio datos personales de los participantes.
